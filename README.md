# 📊 MetricsEngine — Calculadora de Média Corporativa

Uma aplicação web para cálculo de médias e avaliação de indicadores de desempenho, projetada com uma interface corporativa, limpa e responsiva.

---

## 🚀 Funcionalidades

- 📈 **Cálculo Automático**: Média aritmética simples calculada instantaneamente.
- 🏢 **Design Corporativo**: Estilização alinhada a padrões visuais corporativos (*clean design*).
- 🚦 **Indicadores de Desempenho (KPIs)**: Classificação visual baseada nos resultados (*Meta Atingida*, *Atenção*, *Abaixo da Meta*).
- 📱 **Interface Responsiva**: Adaptada para uso em monitores desktop, tablets e telemóveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica de formulários e componentes.
- **CSS3**: Layouts modernos com Flexbox, sombreados sutis e paleta de cores corporativa.
- **JavaScript (ES6)**: Validação de entradas e regras de negócio para exibição de métricas.
